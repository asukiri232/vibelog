На Vercel аккаунт не сохраняется

Это ограничение бесплатного Vercel, не баг сайта: через несколько минут пользователи и посты стираются. Neon не обязателен — выберите один из вариантов ниже.

  1. Beget (рекомендуем для диплома) — у вас уже есть техдомен c99631u8.beget.tech. Там БД и файлы на диске, вход не сбрасывается. Инструкция в файле BEGET.md в репозитории.
  2. Supabase (бесплатно, если нужен именно Vercel) — supabase.com → New project → Settings → Database → Connection string (URI) → в Vercel добавить DATABASE_URL → Redeploy.
  3. Локально + туннель — пока включён ваш ПК, дать преподу ссылку через Cloudflare Tunnel (см. DEPLOY.md).

Пока ничего не подключено — можно пользоваться Vercel как демо, но после простоя нужна новая регистрация.
