Аккаунт на этом демо не сохраняется

Vercel без базы данных стирает пользователей и посты через несколько минут — поэтому вас «выкидывает» и старый вход не работает. Чтобы аккаунт жил постоянно, один раз подключите бесплатную БД Neon (5 минут):

  1. neon.tech → регистрация → New Project
  2. Скопируйте Connection string (PostgreSQL)
  3. vercel.com → проект VibeLog → Settings → Environment Variables
  4. Добавьте DATABASE_URL = строка из Neon, DJANGO_DEBUG = false
  5. Deployments → Redeploy, затем зарегистрируйтесь ещё раз — этот аккаунт уже не пропадёт
